# 星语 StarLang

> 一门用中文写的玩具编程语言。
> **三个独立实现（解释器 / 编译器 / 虚拟机），跑同一段程序必须输出逐字节相同。**

这不是「只能算 `1+2`」的玩具。它有自己的标准库、宏、编译期织入、运行期钩子、
差分测试、自动缩减器，还有一份**每个例子都跑过一遍**的[手册](手册.md)。

```starlang
载入 "标准库.star"

定义 算账(单价, 数量)
    打印 "开始算账"
    返回 单价 * 数量

插入 算账 开头
    打印 "【审计】参数是 " + 单价 + " 和 " + 数量

打印 算账(10, 3)
```

```text
【审计】参数是 10 和 3
开始算账
30
```

> `插入` 是**编译期织进 AST** 的：被插进去的代码能直接看到原函数的参数和局部变量，
> 而不需要改原函数一行。

## 为什么值得看

### 1. 三个实现，一条硬标准

| 引擎 | 文件 | 怎么跑 |
|---|---|---|
| 树遍历解释器 | `starlang.py` | 直接走 AST |
| 编译器 | `starlangc.py` | 生成 Python 源码再 `exec` |
| 字节码虚拟机 | `starlangvm.py` | 编译成指令流，栈式执行 |

同一段程序，三边输出**必须逐字节相同** —— 做不到就是有 bug。

```powershell
python 对比.py            # 30 个 demo，三边逐行比对
python 差分测试.py --个数 1000   # 随机生成 1000 个程序，三边比对
```

这不是「大概一致」，是**机械核对**。这一条逼出了这个项目里最有意思的一批 bug：

- 宏展开的**时机**在解释器里是懒的、在编译器和 VM 里是急的 → 三边结果不同
- 宏展开时重建 AST 节点，把**行号侧表**（`id(语句) → 行号`）弄丢了 → 报错指错行
- VM 里 `跳出` 跳走时没有 `POP_TRY`，处理栈上残留的 handler 会在后面
  **随便一个不相干的错误上突然开火**
- 带标号的 `跳出` 穿过 `尝试` 时没清处理栈 → 同上，第二次循环才炸

### 2. 抓到 bug 之后，自动缩到最小

差分测试抓到不一致时，那个程序通常有一两百行、变量叫 `x1 x2 p3`、
还夹着一堆宏和闭包。人工翻 20 分钟才知道是哪一行。

`缩减.py` 干的是 [delta debugging](https://en.wikipedia.org/wiki/Delta_debugging)：
不停删，只要「删掉之后三边还是不一致」就留下这次删除，直到删不动。

它还带一个**自检**：往真虚拟机里注入一个真 bug（让数字加法永远多算 1），
然后看缩减器能不能从 56 行砍到最小可复现片段。

```
④ 缩减结果：56 行 → 6 行
   ✅ 还是原来那个 bug
   ✅ 砍到 6 行，够小了
```

### 3. 中文关键字，但有一堆同义词

同一行的写法**完全等价**，想得起哪个用哪个：

| 用途 | 写法 |
|---|---|
| 打印 | `打印` `输出` `显示` `说` `print` `echo` |
| 如果 | `如果` `假如` `若` `要是` `if` |
| 定义 | `定义` `函数` `fn` `func` `def` `function` |
| 只要 | `只要` `当` `循环` `重复` `while` `loop` |

中文名字里的字不会被误当关键字：`打印次数 = 5` 里的 `打印次数` 是一个变量名。

### 4. 能吃 Python，也能被 Python 吃

```starlang
引入 "math"
引入 "json" 当 js

打印 math.sqrt(16)                    # 4          真属性访问
打印 math.pi                          # 3.14159…   常量不带括号
打印 js.dumps(["名字": "星语"])        # {"名字": "星语"}
```

反方向也通 —— **Python 当宿主，星语当规则引擎**：

```python
import starlang

m = starlang.星语({"单价": 100})
m.执行("总价 = 单价 * 3")
print(m.环境.vars["总价"])          # 300

m.执行('定义 加税(元) { 返回 元 * 1.06 }')
加税 = m.取("加税")
print(加税(100))                    # 106.0
```

**两个方向都不需要类型转换** —— 因为星语的 `数/文/表/典` 就是 Python 的
`int/str/list/dict`，从第一天起就没包过壳。

## 快速开始

```powershell
git clone <本仓库>
cd starlang

python starlang.py   demo1.star     # 解释器
python starlangc.py  demo1.star     # 编译成 Python 再跑
python starlangvm.py demo1.star     # 字节码虚拟机

python 全检.py                       # 一条命令跑完所有验证
```

> ⚠️ 别直接 `python demo1.star` —— 那是当 Python 跑，会报语法错。
>
> Windows 上如果中文输出乱码，先设：
> `$env:PYTHONIOENCODING='utf-8'; [Console]::OutputEncoding=[System.Text.Encoding]::UTF8`

## 语言一览

```starlang
载入 "标准库.star"

# ── 变量：赋值就诞生，不用声明 ──
名字 = "星语"
版本 = 26

# ── 条件（缩进就是块，也可以写花括号）──
如果 版本 >= 20
    打印 "成年了"
否则如果 版本 >= 10
    打印 "少年"
否则
    打印 "还小"

# ── 遍历（自带快照：边走边改容器不会乱）──
遍历 项 于 [1, 2, 3]
    打印 项 * 10

# ── 函数：默认参数每次调用重算，能引用前面的参数 ──
定义 长方形(宽, 高 = 宽)
    返回 宽 * 高

打印 长方形(3)        # 9
打印 长方形(3, 4)     # 12

# ── 匿名函数 + 高阶函数 ──
打印 映射([1, 2, 3], 匿名(x) { 返回 x * x })    # [1, 4, 9]

# ── 闭包 ──
定义 造加器(起点)
    返回 匿名(x) { 返回 起点 + x }
加十 = 造加器(10)
打印 加十(5)          # 15

# ── 三元 ──
评价 = 如果 版本 >= 18 则 "成年" 否则 "未成年"

# ── 错误处理 ──
尝试
    打印 1 / 0
出错 错
    打印 "抓到了：" + 错
```

### 多重循环一次退干净

```starlang
遍历 甲 于 [1, 2, 3] @找
    遍历 乙 于 [10, 20, 30]
        如果 甲 * 乙 > 20
            打印 "第一个超过 20 的是 " + 甲 + "×" + 乙
            跳出 找
```

标号就是**行尾的 `@名字`**，跟「插入」用的是同一套。

### 宏：参数可以是语句块

```starlang
宏 除非(条件, 动作)
    如果 非 条件
    {
        动作
    }

x = 5
除非(x > 10, {
    打印 "x 不大于 10"
})
```

```text
· 已定义语法「除非(条件, 动作)」
x 不大于 10
```

### 钩子：运行期环绕

```starlang
定义 干活(东西)
    打印 "正在处理 " + 东西

定义 记日志(参数)
    打印 "  [日志] 参数=" + 参数

注册 之前 干活 记日志
干活("苹果")
拔掉 之前 干活 记日志
干活("香蕉")
```

```text
· 已在「干活」的之前挂上钩子「记日志」
  [日志] 参数=苹果
正在处理 苹果
· 已拔掉「干活」的之前钩子「记日志」
正在处理 香蕉
```

### 手册不会腐烂

写文档最怕「代码改了文档没改」——那时候文档比没有更害人。所以立了条硬规矩：

| 标记 | 含义 |
|---|---|
| ` ```星语 ` | **完整程序，必须能跑** |
| ` ```星语片段 ` | 片段示意，不跑（可能故意报错） |
| ` ```text ` | 程序输出，**必须一字不差** |

`验证手册.py` 把每个 ` ````星语 ` 块抽出来真跑，还核对紧跟其后的输出。
写手册过程中它就抓到一个真 bug：`类型(真)` 返回的是「布」而不是「真假」。

## 已知限制

诚实列出来，别到时候踩坑觉得是 bug：

| 限制 | 说明 |
|---|---|
| 文本不能乘 | `"a" * 3` 报错，用 `文重复("a", 3)` |
| 列表不能相加 | `[1] + [2]` 报错，用 `拼接([1], [2])` |
| 没有 `del` | 用内置 `删键(典, 键)` |
| 点号只到「模块」和「方法」 | `math.sqrt` 行；`人.年龄` 不行，只能 `人["年龄"]` |
| 引入的库只能拿模块级名字 | `json.JSONDecoder` 能造实例，但实例的 `.decode()` 调不了 |
| 不支持关键字参数 | `dumps(配置, ensure_ascii=假)` 用不了 |
| 载入没有命名空间 | 名字全局，跟 `from x import *` 一样 |
| 循环保险丝 50 万圈 | 死循环会主动报错而不是转死机器 |

### 故意跟 Python 不一样的地方

这些不是 bug，是设计决定：

1. **`+` 只要一边是文本就拼接**（Python 里 `"a" + 1` 会报错）
2. **默认参数每次调用重算**（Python 只在定义时算一次）
3. **遍历用快照**（Python 边遍历边改会乱）
4. **`取整` 向零取整**，`四舍五入` 是真的四舍五入（不是银行家舍入）
5. **没有隐式类型转换**：`1 == "1"` 是 `假`

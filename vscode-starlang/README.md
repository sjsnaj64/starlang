# 星语 StarLang —— VS Code 扩展

给 `.star` 文件加上语法高亮、括号配对、注释、代码片段。

---

## 装法（二选一）

### ① 直接拷进扩展目录（最省事）

把整个 `vscode-starlang` 文件夹复制到：

```
C:\Users\<你>\.vscode\extensions\starlang-0.1.0\
```

然后**重启 VS Code**。打开任意 `.star` 文件，右下角语言模式会显示「星语」。

### ② 开发模式（改语法时用）

用 VS Code 打开 `vscode-starlang` 文件夹，按 `F5`
→ 会弹出一个新窗口，那里面的 `.star` 就是加载了新语法的。

改完 `syntaxes/starlang.tmLanguage.json` 后在那个新窗口按 `Ctrl+R` 重载即可。

---

## 改词表之后

关键字表在 `../starlang.py` 里（`PRINT_WORDS`、`IF_WORDS` …）。
改了那边以后，在本目录重跑一次：

```
python 生成语法.py
```

语法文件是**自动生成**的，别手改 —— 改完重跑，然后 `Ctrl+R`。

## 高亮规则

| 东西 | 颜色（看主题） |
|---|---|
| 控制流 `如果` `只要` `否则` … | keyword |
| 函数 `定义` `返回` | storage.type |
| 打印 `打印` `输出` `说` | support.function |
| 异常 `尝试` `出错` | keyword.control.exception |
| 逻辑 `且` `或` `非` `真` `假` | keyword.operator / constant.language |
| 宏 / 插入 / 钩子 | keyword.other |
| 内置函数 `长度` `追加` `len` … | support.function.builtin |
| **变量定义** `价格 = 100` 的「价格」 | variable.other.assignment |
| **函数名** `定义 平方(x)` 的「平方」 | entity.name.function |
| **参数名** `定义 平方(x)` 的「x」 | variable.parameter |
| `#` 注释 / `#@标号` / `@标号` | comment / entity.name.tag |
| `"文本"` `'文本'` `\n` 转义 | string / escape |
| 数字 | constant.numeric |

### 变量名只在「定义处」高亮

```
价格 = 100           ← 「价格」上色（这里在造一个新名字）
打印 价格             ← 「价格」是普通颜色
定义 平方(x) { }      ← 函数名、参数名各一种颜色
平方(3)              ← 调用处不上色
```

为什么不做「所有引用都高亮」？因为靠正则分不清某个名字是变量还是别的，
全染色反而满屏花。只在声明处标出来，一眼就知道「哪里是定义」。

## 中文关键字怎么分辨边界

中文之间没空格，`打印次数` 里的「打印」**不该**高亮。
所以每条规则都加了 Unicode 词边界：

```
(?<![\p{L}\p{N}_])  打印  (?![\p{L}\p{N}_])
```

前后都不能紧挨着字母/数字/下划线（汉字属于 `\p{L}`）。
所以：

```
打印 次数      → 「打印」高亮 ✅
打印次数 = 5   → 「打印次数」是整个名字，不高亮 ✅
```

## 代码片段

输入下面任一个前缀，按 `Tab`：

| 前缀 | 出来什么 |
|---|---|
| `如果` / `rg` | 如果块 |
| `如果否则` / `rgyf` | 如果 / 否则 |
| `只要` / `yz` | 循环块 |
| `定义` / `dy` | 定义函数骨架 |
| `打印` / `print` | 打印 |
| `尝试` / `cs` | 尝试 / 出错 |
| `宏` / `hong` | 宏 |
| `插入` / `cr` | 插入 |
| `注册` / `zc` | 挂钩子 |
| `遍历` / `bl` | 按下标遍历列表 |
| `列表` / `字典` / `追加` | 容器相关 |

## 没做的事（诚实说明）

- **没有语言服务器**：不报错、不补全变量名、不能跳转定义。
  真正要做这些得再写一个 LSP，比这个扩展大十倍。
- **没有运行按钮**：现在还得去终端敲 `python starlang.py x.star`。
  （想做的话可以加个任务配置，但先这样）
- 语法高亮是**纯正则**的，不做真正的语法分析。所以像「宏展开后的代码」它看不见。
